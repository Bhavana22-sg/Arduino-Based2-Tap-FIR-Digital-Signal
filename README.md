# Arduino-Based2-Tap-FIR-Digital-Signal

📝 Project Overview

Arduino-Based 2-Tap FIR Digital Signal Filtering System
This project demonstrates the basic operation of a Finite Impulse Response (FIR) filter for digital signal processing. A 2-tap FIR filter is implemented using an Arduino UNO in Tinkercad. Two potentiometers are used to provide the current input sample x[n] and previous input sample x[n-1]. The Arduino applies the filter coefficients and calculates the filtered output using the equation y[n] = 0.5x[n] + 0.5x[n-1]. The input and filtered output values are displayed through the Serial Monitor, while two LEDs provide a simple visual indication of the output level. This project provides a simple simulation of digital signal filtering and demonstrates how FIR filters can be used to process input signals.

🎯 Objective

🔬 Understand the basic concept of FIR (Finite Impulse Response) filters.
⚙️ Design a simple 2-tap FIR digital filter using Arduino.
🎛️ Provide input samples using potentiometers.
🧮 Calculate the filtered output using FIR coefficients.
📊 Display input and output values through the Serial Monitor.
💡 Indicate the filtered output using LEDs.
📡 Demonstrate the basic application of FIR filters in Digital Signal Processing (DSP).
🖥️ Simulate the complete circuit using Tinkercad.
